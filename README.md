# PBH Formation Lab

Interactive primordial black hole formation simulations in English.

## Live apps on Vercel

| Version | Open the app | Source file |
| --- | --- | --- |
| **Simple visual simulation** | [Launch Simple PBH Lab](https://pbhformation.vercel.app/) | [`index.html`](index.html) |
| **Computational Einstein–Euler simulation** | [Launch Computational PBH Lab](https://pbhformation.vercel.app/pbh_formation.html) | [`pbh_formation.html`](pbh_formation.html) |

The simple version illustrates collapse and dispersal with a schematic model. The computational version numerically evolves the spherically symmetric Einstein–Euler equations for a radiation fluid; it is an experimental educational solver, not a research-validated code.
